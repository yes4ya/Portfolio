# Audit 001 - Portofolio Yesaya Roy Nugraha

Tanggal: 2026-11-12
Mode: AFTER
Cakupan: `src/`, `public/`, `index.html`, `package.json`, `tailwind.config.js`, `vite.config.js`, `postcss.config.js`, `README.md`, `DATA-YANG-KURANG.md`
Status: belum ada file proyek yang diubah. Hanya laporan ini yang dibuat.

## Ringkasan

- Stack: React 18 + Vite 6 + Tailwind CSS 3, data tunggal dari `src/data/portfolioData.json`.
- 9 komponen, semuanya section-level, tanpa router, tanpa state global, tanpa TypeScript.
- Tema gelap tetap (fixed dark), tanpa toggle.
- Animasi memakai `Reveal` sendiri (IntersectionObserver + CSS), bukan Framer Motion.
- OG/Twitter tag sudah ada, tetapi metadata teknis SEO belum lengkap.
- Tidak ada analytics, tidak ada backend form, tidak ada lint/test.
- Tidak ada `DESIGN.md`. Keputusan warna, tipografi, dan motion belum ditulis alasannya.

## Temuan Bernomor

Prioritas mengikuti tier aturan: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.

### HIGH

1. **R-40**: Foto hero 822 KB dan preload menunjuk file yang tidak dipakai.
   `src/data/portfolioData.json:15`, `index.html:25`, `src/components/Hero.jsx:86`
   Alasan: `profile-yesaya-cutout.png` (800x1200, 822 KB) adalah kandidat LCP, sementara `index.html` mempreload `/profile-yesaya-dark.jpg` (45 KB) yang tidak pernah dirender. `profile-yesaya.webp` (41 KB) dan `profile-yesaya.jpg` (75 KB) juga tidak terpakai.

2. **R-24 / R-26**: Link brand di navbar memakai `href="#"`.
   `src/components/Navbar.jsx:24`
   Alasan: tidak ada tujuan nyata, hanya menambah `#` ke URL.

3. **R-26 / R-27**: Form kontak menyatakan sukses tanpa bukti terkirim dan tanpa state error.
   `src/components/Contact.jsx:33-39`, `src/components/Contact.jsx:124-128`
   Alasan: `setSent(true)` dijalankan tepat setelah `mailto:` dipanggil, jadi pesan sukses muncul walau tidak ada aplikasi email yang terbuka.

4. **R-32 / R-39**: Input menghapus outline dan hanya menandai fokus lewat warna border.
   `src/components/Contact.jsx:155`, `171`, `188`
   Alasan: `focus:outline-none` menimpa `:focus-visible` global, sehingga indikator fokus menjadi perubahan warna saja.

5. **R-27**: Daftar proyek, keahlian, dan pendidikan tidak punya empty, loading, atau error state.
   `src/components/Projects.jsx:24`, `src/components/Skills.jsx:37`, `src/components/Education.jsx:16`
   Alasan: jika array data kosong, section tetap tampil sebagai kotak kosong tanpa pesan.

6. **R-39**: Ikon dekoratif dari lucide tidak diberi `aria-hidden`.
   `src/components/Hero.jsx:47,58,67,77`, `src/components/Projects.jsx:52,63,89`, `src/components/Contact.jsx:92,110`
   Alasan: lucide-react 0.475 tidak menambahkan `aria-hidden` otomatis, dan ikon ini murni dekoratif di samping label teks.

### MEDIUM

7. **R-40 (kasus stylesheet)**: Google Fonts dimuat sebagai stylesheet render-blocking di `head` dengan 9 bobot.
   `index.html:26-28`
   Alasan: Inter 300-800 dan JetBrains Mono 400-600 diminta sekaligus. R-40 secara harfiah melarang script pihak ketiga yang render-blocking, bukan stylesheet, jadi ini peringatan performa, bukan pelanggaran keras.

8. **R-19 / R-05**: Animasi masuk yang sama dipakai berurutan pada lima section.
   `src/components/Reveal.jsx:22-35`, `src/App.jsx:29-43`
   Alasan: fade dan rise identik di About, Skills, Projects, Education, Contact, sehingga gerak terasa seperti efek template, bukan penuntun perhatian.

9. **R-14**: Proyek, pendidikan, dan kontak memakai kartu bergaya sama.
   `src/components/Projects.jsx:27`, `src/components/Education.jsx:19`, `src/components/Contact.jsx:62,78,96,116`
   Alasan: border `#262626`, latar `surface`, dan radius serupa dipakai untuk tiga jenis konten berbeda, jadi tidak ada hierarki visual.

10. **R-06**: Inter dan JetBrains Mono dipilih tanpa alasan tertulis, dan label mono uppercase ber-tracking lebar dipakai di semua section.
    `tailwind.config.js:25-43`, `src/components/About.jsx:11`, `src/components/Skills.jsx:11`
    Alasan: pola ini justru yang disebut R-06 sebagai default tanpa alasan. Pilihan fontnya bisa dipertahankan, tetapi alasannya belum pernah ditulis.

11. **R-21 / R-34**: Tema gelap dipaksa lewat `color-scheme: dark`, tanpa opsi terang.
    `src/index.css:8`, `index.html:30`
    Alasan: portofolio developer punya alasan kuat untuk gelap, tetapi keputusan itu belum dinyatakan, dan pengguna yang butuh mode terang tidak punya jalan keluar.

### LOW

12. **R-05**: Lima section memakai komposisi yang sama persis.
    `src/App.jsx:27-44` dan semua file section
    Alasan: grid 3/9, label mono kecil, dan padding `py-12 sm:py-16` identik, jadi ritme halaman tidak berubah dari atas ke bawah.

13. **R-11**: Radius bercampur tanpa hierarki.
    `rounded`, `rounded-md`, dan `rounded-lg` dipakai bergantian di navbar, kartu, tombol, dan embed.
    Alasan: tidak ada aturan radius yang tertulis, sehingga variasinya terbaca acak.

14. **R-08**: Panah `ArrowUpRight` dipasang di hampir semua tautan keluar.
    `src/components/Hero.jsx:49,60`, `src/components/Projects.jsx:63,89`, `src/components/Contact.jsx:92,110`
    Alasan: panah bisa berfungsi sebagai penanda tautan eksternal, tetapi fungsinya belum ditulis dan dipakai terlalu merata.

15. **R-31**: Tidak ada `DESIGN.md` atau catatan keputusan desain.
    Akar proyek
    Alasan: palet, tipografi, dan motion belum punya alasan satu baris, padahal R-31 adalah kunci seluruh aturan.

## Gap di Luar Aturan

- **Konten pengalaman tidak dirender**: `personal.experience` berisi 3 entri (magang UI/UX di Penerbit Erlangga, asisten dosen, IT support) tetapi tidak ada komponen yang menampilkannya. `experience` tidak dipakai di mana pun.
- **Field data menganggur**: `personal.headline`, `skills.categories[].items[].level`, `projects[].featured`, `projects[].hasEmbed`.
- **Data ganda**: email, GitHub, dan LinkedIn ada di `personal` dan di `contact`.
- **String hardcoded menduplikasi JSON**: `Hero.jsx:103` ("S.Kom UKSW"), `Hero.jsx:111` ("React, Tailwind CSS"), `Hero.jsx:115` ("Salatiga, Indonesia").
- **README tidak sesuai kode**: klaim "filter kategori" di Skills, "interactive code terminal" di Hero, dan "visualisasi interaktif" di Projects tidak ada di komponen.
- **Aset mati**: `profile-yesaya-dark.jpg`, `profile-yesaya.jpg`, `profile-yesaya.webp` tidak dipakai.
- **SEO teknis belum lengkap**: tidak ada `canonical`, `og:url`, `og:image:alt`, `twitter:site`, JSON-LD Person, `robots.txt`, `sitemap.xml`, atau manifest.
- **Tidak ada analytics** sama sekali.
- **Tidak ada ESLint, Prettier, test, atau CI**. `package.json` hanya punya `dev`, `build`, `preview`.
- **Tidak ada konfigurasi hosting** (`vercel.json` / `netlify.toml`) untuk cache header dan fallback SPA.
- **Tidak ada halaman 404 atau kebijakan privasi**.
- **Tidak ada error boundary** di React.

## Catatan Verifikasi

- Audit dilakukan lewat pembacaan kode dan log `dev-server.log` / `preview.log`. Aplikasi tidak dijalankan ulang pada sesi ini.
- Skor Lighthouse dan Core Web Vitals tidak diukur, jadi tidak ada angka performa yang diklaim.
- Kontras teks utama sudah dihitung manual: `#a1a1a1`, `#8a8a8a`, dan `#7d7d7d` di atas hitam atau `#121212` berada di kisaran 5:1 sampai 8:1, lolos WCAG AA.
